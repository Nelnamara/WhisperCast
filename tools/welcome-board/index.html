Welcome, what’s new, and a three-step tour

A window that tells new players what WhisperCast does and old players where it came from, with a small moving demo of the queue window, then a three-step tour to set it up. CDTL3 already has both halves (a What’s new window with running samples at the top, and a three-step tour on the real frames), so the choices here start from those.

Pick one choice per idea, or None of these, and add a note. The history text is a draft: put your own words in its note.

The welcome window

The same content three ways: the demo, what it is, where it came from, what’s new since 2007, and a button that starts the tour.

Every client. Drawn in Suite dark; it follows your Overall look like the queue window. /wc welcome opens it any time.

The demo

What the moving sample shows. These run here as they would in the game: a whisper arrives, the request queues with the note and the glow, the key is pressed, the spell goes out and the window empties. About eight seconds, then again.

Every client. Built from the addon’s own frames with the game’s animation tools, so it needs no video and follows your look. It runs only while the welcome window is open.

The three-step tour

The same three steps each way: 1 your queue window (drag it where you like), 2 bind your Cast key, 3 tell your group what to whisper. A Try it button whispers you “motw” as a test (/wc test motw, nothing is sent).

Every client. /wc tour runs it again any time.
